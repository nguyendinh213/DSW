# Data Warehouse and Analytics Project

**Project: SQL Data Warehouse and Analytics**

This project focuses on building a modern data warehouse using SQL Server to integrate sales and customer data from CRM and ERP systems.

The workflow includes loading raw data, cleaning and standardizing it through ETL pipelines, and organizing it into a structured data model using a star schema. I also use SQL to analyze customer behavior, product performance, and sales trends to generate business insights and support data-driven decision-making.

Through this project, I aim to strengthen my SQL skills, understand the data engineering workflow, and learn how to transform raw data into reliable, analysis-ready datasets.

##

Languages / Tools

- Python: Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
- SQL (file Ecommerce Sales Analysis.sql)
- Power BI (file .pbix và 3 dashboard)

- RFM Customer Segmentation (nhận diện khách VIP/loyal)
- KPI Design (revenue, orders, customers)
- Sales, Customer và Product Analytics (phân tích theo quốc gia, top sản phẩm)
- Business Intelligence, Data Visualization, Dashboarding, Data Storytelling
